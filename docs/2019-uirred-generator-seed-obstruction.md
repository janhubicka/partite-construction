# Five-vertex obstruction to the irreducible-generator shortcut

9 October 2026. This is an adversarial audit of a proposed shortcut in
the positive 2019 multiamalgamation proof. It is **not** a counterexample
to Theorem 2.18, Lemma 2.27, or protected coordinate powers themselves.
Its finite combinatorial core now has a Lean formalization, but the bridge to the full structure-level U-irreducibility predicate is not yet formalized.

## Model

Language: directed binary E, ternary closure relation R. The single
closure rule gives each induced two-vertex E(0,1) root a unique R extension.
On vertices 0,1,2,3,4 take the following and no other positive tuples:

    E(0,1) -> R(0,1,2)
    E(0,2) -> R(0,2,1)
    E(1,3) -> R(1,3,0)
    E(2,4) -> R(2,4,0)
    E(3,4) -> R(3,4,0)

Every root has exactly one closure tuple, and every closure tuple has a
valid root; thus the structure is U-closed under the 2019 semantics.

## Indecomposability

The distinct sets supporting the closure relation tuples are

    X={0,1,2}, Y={0,1,3}, Z={0,2,4}, W={0,3,4}.

In a free decomposition into two U-closed induced proper sides, each of
X,Y,Z,W lies wholly on one side. Since X union W = V and Y union Z = V,
each opposite pair must split across the sides. Up to swapping, the only
possibilities are (X,Y) versus (Z,W), or (X,Z) versus (Y,W).

In the first, the side containing Z,W contains {0,2,3,4}; closure of
the root E(0,2) forces vertex 1, hence the side is all V. In the second,
the side containing Y,W contains {0,1,3,4}; closure of E(0,1) forces 2,
again making that side all V. Properness is contradicted. Therefore the
model is U-irreducible.

## No ordinary irreducible generating seed

Neither 3 nor 4 is a closure output, so every generating set contains
both. The set {0,3,4} is closed, so it must also contain 1 or 2 to
generate all five vertices. But no positive relation tuple contains
both 1 and 4, or both 2 and 3. Every generating set therefore fails to
induce an ordinary irreducible structure.

The U-size is three; the minimal generating sets are {1,3,4} and
{2,3,4}. Both are ordinarily reducible.

## Reproducible finite validation

Run:

    python3 scripts/check_2019_uirred_seed.py

The program checks the full root/closure relation, all 32 induced
vertex subsets, all 1024 ordered pairs of candidate free-amalgam sides,
all ordinary irreducible induced seeds, and the minimum generating rank.
It passed locally. A companion Lean file,
PartiteConstruction/Ramsey/ClosureFiniteSeedObstruction.lean, certifies
the finite propositional closure/cover calculation, the nonexistence of
an irreducible generating seed, and rank three. The Lean propositions
encode the explicit five closure dependencies; they do not yet instantiate
the full RelStructure IsUIrreducible predicates.

## Impact on the positive proof

This refutes the universal auxiliary shortcut that every closed
U-irreducible structure is generated by an ordinary irreducible seed.
The conditional PR #177 theorem named
power_part_protected_of_irreducible_generators therefore has a genuinely
additional hypothesis that fails for general closure descriptions.

The local positive theorem part_embedding_on_irreducibly_generated_test
remains fully useful for tests that are irreducibly generated. Higher
coordinate powers require another argument for multiply generated
U-irreducibles. Do not mark full protected projection, the iterated
rank step, or Theorem 2.18 as validated from this shortcut.

The manuscript and literal published definitions are unchanged.
