# Complete OLD function graph homomorphisms imply original-2019 partial function maps

22 October 2026. The true global partite projection is **original-partial**, not total-fibre/domain-reflecting.

Let E be an OLD complete-mask relational structure with unique entire output sets for each primitive input tuple. Its generic decoder D has Option(Set)-valued genuinely partial functions. Suppose f is an OLD relational homomorphism from E into the **canonical** complete-mask graph of a genuinely partial control T, using a chosen output-part map on T.

A decoded defined source application F_D(x)=some U is witnessed by one OLD relation tuple that enumerates the ENTIRE value set U, with a surjective equality-pattern map from primitive arguments. OLD homomorphism preservation sends this COMPLETE tuple into the canonical OLD graph of T. By the definition of that canonical relation, the target value F_T(f∘x) is exactly some f[U]; no additional target output is possible. The proof also works for U=∅, because the complete zero-output tuple remains a genuine relation of arity equal to the input-root size.

Ordinary primitive relations are preserved by the OLD graph homomorphism. Nothing is asserted when D.func F x=none: a source-undefined function is permitted to become defined in the control. This proves exactly IsOriginalPartialHomomorphism, NOT the stronger full/domain-reflecting map. In a final U-closed tagged C with protected canonical B-copy coverage, complete source value uniqueness is already kernel-certified in merged #481; hence the same theorem applies to its OLD reduct with no extra target normalization premise.

**Validation boundary.** A native Hales–Jewett projection or a relational 2019 iterated picture projection must be shown to preserve the WHOLE OLD complete mask relations before applying this theorem; positive output-incidence preservation alone is insufficient for a multivalued function. This lemma does not prove the maximal mixed strict functional B-tree target extension, and it does not change S or its exact image f[S].
