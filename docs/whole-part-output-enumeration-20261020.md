# Source coverage of the finite complete-output-part language

For a defined value U of a function on an arbitrary tuple, let T be the finite subtype of vertices in U. Output transversality makes the part map T→P injective. Therefore |T|≤|P|. Enumerate T by Fin |T| and use the parts of this enumeration as an injective label tuple; this gives a symbol in the bounded output-part language. The corresponding list of vertices enumerates exactly U. The empty value is included with width zero. No assumption of distinct inputs or disjointness of inputs and outputs is necessary.

This is the finite-language *source coverage* lemma, complementary to exact whole-fibre restriction and unique outputs. It is not yet a U-closure description; the old active-root/domain relations and the complete input equality pattern still need to be incorporated to apply the 2019 theorem.
