# Theorem 2.18: actual Picture subhistories and coordinate retractions

9 October 2026, PR #174. This is positive proof work following #173.
The working closed-test predicates remain distinct from the literal 2019
ones. No frozen manuscript prose is changed. The new Lean statements must
pass the full combined build and permitted-axiom audit before validation.

## 1. Work in the existing attachment, not a new abstract diagram

The source is `Attachment.attach Old S Core maps`, with the exact native
carrier Core + (Index x (Old minus S)). It contains the entire core and a
fresh old-picture copy for every selected attaching map. All embeddings
and relation tuples are those of the existing attachment implementation.

If S is relatively U-closed in Old, then deleting the exterior of any
one copy leaves a relative U-substructure of the whole attachment.
A closure tuple from a different copy stays in the rest. For a tuple
from the deleted copy, roots remaining in the rest all lie in S, so
relative closedness puts every output in S as well.

In a U-closed attachment of a U-closed Old, an embedded U-closed
U-irreducible test lies entirely in the core or one old copy. This is
proved on the test's own carrier using a cover by two relative closed
sets and the actual tuple decomposition. No hereditary graph
irreducibility of Old, Core or S is assumed.

Compatible protected maps of the core and each old copy consequently
fold to a protected map of the whole. The common target is arbitrary;
no target free-amalgamation or strong-amalgamation axiom enters here.

Implementation: `ClosureClosedCover.lean`, `ClosureAttachmentFold.lean`.

## 2. Closure cannot introduce new exterior copy indices

Let e:F->Attachment be a full embedding and let G generate F. If an
exterior vertex e(x) belongs to copy i, then some e(g), g in G, already
belongs to the exterior of i. Otherwise all generators lie in the
relative closed complement of i's exterior; closure would put x in
that complement too.

Thus F embeds, with its ORIGINAL carrier and relation structure, in the
subattachment formed from the core and just the copies selected by its
generators. The selected subattachment is induced in the original one;
its range is relatively U-closed. It is therefore intrinsically closed
if the full attachment is closed. This selected ambient can be larger
than F, but the tested F is never replaced by a larger weak vertex set.

Implementation: `ClosureAttachmentSubhistory.lean`, including
`exterior_index_from_generator` and `factor_through_generator_subfamily`.
The latter permits any selected family containing all generator exterior
indices; it does not require constructing a new index-cardinality API.

## 3. A common retraction reuses the previous rank invariant directly

Suppose r:Core->Old is a protected map satisfying

    r(maps_i(x)) = x for x in S

for the selected indices i. Fold r on the core with the identity map on
each old copy. This constructs p:Attachment->Old, and p is identity on
each selected entire old copy, not merely on its boundary.

If every closed substructure of Old of U-size <= n has a K-completion,
then any F embedded in this retracted attachment and generated by at most
n vertices has a K-completion. The image of those generators has at most
n vertices; complete its closed hull in Old and precompose. No requirement
that both source sides have strictly smaller absolute rank is made.
Protected-copy coverage of Old is preserved by the same retraction.

Implementation: `ClosurePictureRetraction.lean`.

## 4. Instantiate the retraction using the native Hales--Jewett power

Use the existing induced coordinatewise power of the restricted old
partite system, and the existing `Induced.lineEmbedding` maps. Evaluation
at coordinate k is positive. If the part projection of this power is a
working protected map, coordinate evaluation is protected as well: its
composite with the positive old part map is exactly that projection.
`IsClosedUHomomorphismEmbedding.of_comp_homomorphisms` proves this
reflection through positive factors rather than assuming it.

A parameter coordinate of a line evaluates the line map back to the
original support vertex. Therefore, if the exterior lines met by G share
a parameter coordinate k, select all lines with parameter at k. Section 2
factors F into this subattachment, Section 1 gives its closedness, and
coordinate evaluation supplies the common retraction. Section 3 completes
F using the old rank-n invariant.

This is `Induced.completion_of_common_generator_coordinate`. It includes
the case of generators meeting only one exterior line: use that line's
nonempty parameter set. The tested structure may also contain vertices
anywhere in the core, so it need not lie in that one old copy.

Implementation: `ClosurePictureCoordinate.lean`. The coordinate and line
maps are native; no surrogate functional encoding or unproved simultaneous
completion diagram is used.

## 5. Necessary qualifications and the next branch

The common-coordinate requirement is LOCAL to one test's exterior lines.
Imposing it on the entire Ramsey family would be false: colour a word by
its entry at that coordinate. Every line having a parameter there contains
all alphabet colours. The negative theorem
`no_monochromatic_line_with_fixed_parameter` explicitly certifies this
obstruction for an alphabet with two distinct elements.

The full actual Picture may index more than the native line family used
here. Passing to a line-indexed subattachment and establishing its
sufficiency for every target test is a separate construction obligation;
this patch does not identify it with every embedding-indexed Picture.

Nor do we infer the protected core projection from mere ordinary
partiteness. The native-power projection must preserve the working closed
tests, and the full attachment must be U-closed. Those hypotheses remain
visible. This proof does not cover the temporarily nonclosed recursive
picture simply by changing its name.

The next rank-step case has generator exterior lines with NO common
parameter coordinate. Its treatment must use the constant-coordinate
maps and the existing closed-boundary completion machinery, or further
history information. It cannot be disposed of by declaring a global
common coordinate or by the generic absolute boundary-rank shortcut
refuted in #173.

The semantic bridge to Definition 2.17, the full Ramsey pass, all branches
of the rank increase and iteration, and transport to partial-function
languages remain open. No theorem labelled Theorem 2.18 or Lemma 2.30 is
marked complete by this patch.
