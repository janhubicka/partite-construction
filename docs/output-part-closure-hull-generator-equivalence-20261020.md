## Main equivalences

For every literal vertex set S⊆V(B):

\[
  \operatorname{cl}_{B}(S)
     =\operatorname{cl}_{B^P}(S).
\]

Proof: by definition, the closure of S is the intersection of ALL
sets T containing S that are closed under all function values. The
already kernel-verified exact singletonization lemma states

   B.IsClosed T iff B^P.IsClosed T

for every T, without taking any hull. Consequently the two families
of closed supersets of S are identical, and their intersections agree.

The following statements are therefore equivalent, on the same
source carrier and with the same generators:

   S generates B in the native multivalued language
     iff S generates B^P in the singleton split.

For any n, B is generated by at most n vertices in one language
iff it is generated by at most n in the other. The witness

so **no rank or vertex budget is inflated**.

## Independent adversarial audit

* **Multi-valued fibres:** all parts q are included; one
  native F may generate several new vertices at once.
  Omitting any output part would falsify closure equality.
* **Exact tests:** this compares closure operators ON the
  same seed S. It does NOT authorize replacing a weak test
  S of size n by cl(S) and charging the same n vertices.
  The separate generated-rank induction is explicitly
  about seed sets, not the cardinality of their closure.
* **Full source maps:** the lemma is internal to one
  genuine System B. It does not strengthen an EHN map
  to global fibre-surjectivity or reflect undefined domains.
* **Nullaries and repeated inputs:** every primitive output
  remains in its output-part symbol, including constants.
  The native closure equivalence is valid without positive
  arity; the 2019 fresh positive-root tagging requires
  a separate nullary reduction.
* **No strict target inference:** closure/generator equivalence
  says nothing about compatible strict B-tree target histories
  across a maximal nonclosed mixed HJ test. The known
  marked-edge and C5 audits remain in force.
