## Exact contract

For an arbitrary genuine `Option(Set)` partial structure and any exact tested vertex set S, the identity from the WHOLE-fibre weak restriction to the CLIPPED weak restriction preserves every originally defined source application, including defined-empty, and has the precise **original 2019 source-defined partial homomorphism** property. It does **not** reflect source-undefined domains. A general generator-image inequality immediately proves: if whole-fibre S is generated by at most n vertices, then clipped S is generated by at most n vertices.

The canonical tagged `USize` version then composes the two already-checked exact weak same-carrier dictionaries in the native functional partite system: **whole-mask USize(S) ≤ n implies split-output clipped USize(S) ≤ n**. This is valid on every mixed weak S, with no full closure assumption, no output singletonization of the original fibre, and no cardinality-of-hull penalty. This is the one direction missing from PR #615's *equivalence on closed support* and the genuinely transversal rank-gap regression PR #620 proves the converse cannot be added generally.

For any actual EHN Stage T, the original weak part projection `T.system.part` obeys exact-image WHOLE USize monotonicity. Consequently a whole-mask source rank at most n implies a CLIPPED tagged USize bound at most n on its literal projected control image `part '' S`. Unlike the theorem on the chosen closed attachment support, this holds for **every** weak tested S of the actual stage.

## Scope

The map from whole weak to clipped weak is only source-defined; it is not a full embedding. No weak test is enlarged or replaced by a generated hull. The two canonical tagged languages have different active-domain masks and need not be isomorphic. Nothing here solves the intrinsic-local to ambient-relative H-class local-completion hypothesis, strict mixed-root B-tree completion, or class-relative target selection.
