## Genuine native assumptions

Work in one actual functional partite system `B : System L P C` with **set-valued, transversal operation fibres** and its EHN part projection `p=B.part : C→P` to the functional control `D`. Suppose its source structure is a **full** functional free amalgam of `Left` and `Right`. Fix a **full** selected `alpha : A↪D` which contains the projected attaching root.

Let `S : Finset C` be the **literal weak test**, not its function-closure, such that `|S|≤m+1` and both source-side images omit a tested point. Assume the genuine strict rank-`m` predecessor history invariant for `D`, protecting all ambient full `A`-copy intersections and arbitrary history lists.

The verified sharp theorem either completes `S` into one strict full-functional `Base`-tree, or says `|p[S]|=m+1` and one exact occupied side `X=S∩range(i_L)` (or the right analogue) **exposes** an actual control output:

\[
  F,\quad (x_i)_{i<\mathrm{arity}(F)}\subseteq X,\quad
  p(x_i)\in\alpha(A),\quad
  q\in F_D(p(x)),\quad q\notin p[X].
\]

The finite equality forces `|S|=m+1` and **`p|S` injective**. It does NOT force injection on the closure generated by `S` or on vertices outside `S`.

## Axis I: location of q relative to the exact weak test

- **External:** `q∉p[S]`. No literal tested vertex represents q.
- **Cross-side:** There is **exactly one** `z∈S` with `p(z)=q`. Because `q∉p[X]` and the free amalgam's two sides cover every source vertex, `z` belongs to the **opposite-side exterior** (not to the common root).

This location dichotomy is new to the maximal-rank specialization; the old exposed-output criterion asserted only `q∉p[X]`, and properly made no global claim.

## Axis II: source function fibre on the SAME displayed tuple

The checked EHN `map_func_of_nonempty` supplies the genuine original-2019 partial semantics, with **no domain reflection for undefined inputs**.

- **Undefined:** The whole ambient source fibre `F_B(x)` is empty even though `F_D(p(x))` contains q. The already checked EHN theorem gives a **proper full free decomposition of the source input-generated hull** `\langle x\rangle_F`.

These axes are logically independent, giving four concrete cases for the **same F,x,q**.

| | External q | Cross-side q |

### The exact rank-budget obstruction

In the omitted-value cases, `|S∪{y}|=m+2`. Thus **closing** the tested weak set by inserting y would already breach the rank-`m+1` source budget, even if that one output sufficed for closure (it need not). Moreover:

- External q: `|p[S∪{y}]|=m+2`.
- Cross-side q: `|p[S∪{y}]|=m+1` — a projection collision appears on the enlarged set, but the image has **not** dropped to rank m.

Consequently neither “close S and apply induction” nor “add y and invoke the rank-m small-image case” is justified. A projected generator-rank statement cannot be silently converted to a cardinality statement on the resulting closure hull.

In the undefined cases, the input-generated hull decomposition is **only a diagnostic**. It does not imply a strict decomposition of the original weak test, nor smaller generator rank for all target sides. No hypothesis permits replacing `S` by this hull.
