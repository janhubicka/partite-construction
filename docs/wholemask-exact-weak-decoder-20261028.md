# Decoding induced ambient OLD complete-mask data recovers exact weak functions

28 October 2026. This bridges the final local K-completion proof in the verified 2019 two-pass profile construction to the genuine weak-substructure presentation.

Given a finite genuine partial Option(Set) source A with transversal whole outputs, a literal vertex subset S, and an actual part map, compare (i) the OLD complete-mask relational graph of the whole-fibre weak restriction to S, with (ii) the ambient OLD complete-mask graph induced on exactly S. Their active OLD domain masks may differ: the induced ambient structure retains a domain activation even when its full output leaves S, while the true weak partial function becomes undefined. This difference is correct and must not be erased.

However, the complete output VALUE tuple relations coincide exactly, by the already checked `wholeWeakInduce_wholeMaskPatternGraph_output_iff`. Every full value witness is therefore shared by both OLD graphs, including a genuine zero-output witness for defined-empty values. Whole-fibre weak restriction preserves output transversality; its canonical OLD graph has faithful Option(Set) decoder. The induced ambient OLD graph has precisely the same complete value witnesses and inherits their uniqueness, so its decoder produces the SAME weak Option(Set) value on every primitive input tuple.

Primitive relations agree definitionally on the exact subset. No source S is replaced by its ambient closure hull and no projected generator count is inflated. The result does not claim the two OLD relational structures are identical, and therefore does not incorrectly preserve ambient domain predicates as functional weak domain predicates.

The follow-up is to apply the checked original-partial homomorphism semantics to exact weak tests and their relational K-completions, retaining the domain/whole-value distinction.
