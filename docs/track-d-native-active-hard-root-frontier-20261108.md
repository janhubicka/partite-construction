## Proposed new positive proof interfaces (subject to CI)

**Active whole root (#571):** if the *entire actual closed common separator* is generated by inputs of a genuinely source-defined function application, then it is irreducible even when it requires two or more generators. The canonical EHN map becomes a FULL root embedding into A, then into Base. With the rank-n generated strict completion hypotheses on the two actual closed source sides, the already checked irreducible-root relative synchronization supplies **two relative B-tree extensions over that same canonical map**.

**Paid side ranks (#574):** rather than ASSUME rank-n for the two new closed sides, start from one actual whole closed-test generating set G with |G|≤n, a root generator set Roots and, for EACH side, an exterior subset of G of cardinal at least |Roots|. The verified exterior reserve lemma then proves both side ranks ≤n, and the old-stage and power-core rank-n predecessors give their absolute strict completions. With #571's active root, the relative synchronization applies. This is a genuine native one-copy attachment criterion, not a generic unrelated gluing diagram.

**Local EHN atlas (#573):** for every vertex x of the actual closed common separator, its one-generated FULL function hull is irreducible and embeds FULLY in selected A, preserving the canonical label on the nose. These local charts agree on TRUE source overlaps and are injective individually, but their images can overlap at source-distinct vertices; relations and undefined function domains between charts also need reflection for a GLOBAL full embedding. The draft full-embedding iff lemma isolates these three defects. This local atlas is **not** a complete strict target-root tree.

## Remaining cases, not proved

1. **Label-collision / reducible separators.** If two root vertices share a canonical A-label, the separator cannot be generated by inputs of one source-defined function (active-root route) and cannot sit FULLY in any irreducible EHN collar over the same A (collar route). Local one-generated A charts may have extra target hits. A history-sensitive target STRICT B-tree Start carrying a compatible *family* of root charts with no false relative hits is required.
2. **Insufficient exterior GENERATORS.** Even with an irreducible active root, genuine mixedness provides only one tested exterior VERTEX on each side. It does **not** produce a generator-reserve subset of G of cardinal ≥|Roots|. Root cardinality and function-closure cardinality cannot be charged to the vertex rank; a new history-sensitive generator budget or a target construction avoiding root-seed payment is needed.
3. **Multiple Hales–Jewett line parameters.** The checked common-parameter-coordinate retraction works for restricted line families but is insufficient for the full Hales–Jewett Ramsey arrow. The verified native three-line C7 example disproves a naive all-line global shadow. Its old control carries a triangle, so the example does NOT satisfy the genuinely strict K2-tree predecessor hypothesis and is NOT a counterexample to the correctly conditioned n-pass theorem.
4. **Defined-empty Option(Set) versus undefined.** The legacy `Structure` representation uses empty source fibre for 'undefined'; it does not represent an active defined-empty set value independently. Canonical `Option(Set)` correspondence is handled separately by Track E. No statement in the current old native EHN proof should silently identify these cases.
