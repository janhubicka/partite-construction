# Complete-mask relation closure = 2019 relative U-substructures

The old finite complete-mask relational source has separate graph and active mask-domain relations for each function input equality pattern and whole output-part mask. Define a validity condition saying that every complete-value graph tuple has injective distinct input coordinates and activates its matching OLD domain relation. Genuine source graphs satisfy it; it is hereditary under inducing to any exact vertex subset.

For a valid old graph E, closure under complete-value tuples means: whenever all distinct input vertices of a graph tuple lie in Q, every output vertex lies in Q. This coincides with the 2019 relative U-substructure condition of the FULL-ROOT tagged expansion. One implication reads the complete-value tuple from a fresh closure relation. Conversely take a complete graph tuple with a requested output coordinate. Its positive output coordinate forces a positive output mask; positive original function arity implies a positive distinct-input root. Validity supplies active old domain incidence. Extract the FULL old root pattern on the exact input vertices, and form the corresponding tagged closure tuple. Its U-closedness forces the selected output into Q.

This generic relation lemma is valid even on the OLD relational structure induced from an ambient source on a nonclosed weak vertex set. In that setting ambient mask-domain information persists, while the individual original function application may have become undefined in the whole-fibre weak restriction.
