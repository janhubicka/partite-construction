# Track E: internal native B-cover after closed-root relational saturation (15 November 2026)

## Exact theorem and proof (English-first)

Work in the genuine whole-mask profile/tag language of a finite transversal partial
set-valued function structure B, with positive function arity. Fix an ACTUAL finite
U-closed noncanonical tagged source Q, its selected ordinary homomorphism-embedding
q:Q→Control, and a canonical tagged B whose U-closedness and hereditary ordinary
irreducibility are certified. Assume the SAME Control has internal tagged-B extension,
and the ACTUAL Q has external B protection of all U-closed U-irreducible embedded tests.

The closed-hull finite saturation theorem (merged #698) gives a single finite tagged
source Q' and inclusion j:Q↪Q' with:
(1) U-closed Q'; (2) selected q':Q'→Control a homomorphism-embedding with
q'∘j=q; (3) inherited external protection; (4) INTERNAL tagged-B extension
for every ordinarily irreducible exact test in Q'.
The tagged Ramsey arrow persists along j. The same small test is NEVER replaced
by its closure: closed hulls are only used as B-attachment roots.

For an exact U-closed U-irreducible S⊆Q', external protection supplies a full
embedding Q'|S↪tag(B). If tag(B) belongs to a closed-U hereditary K whose
members are ordinarily irreducible, Q'|S is ordinary irreducible. Thus (4) yields
an internal tagged-B full embedding whose range contains S. The covered whole-mask
decoder theorem (local PR #705, already checked on its original head) converts that
internal tagged embedding, on exactly its original vertex map, to a full genuine
Option(Set)-valued B embedding; the checked collapse-domain embedding then produces
a full NATIVE set-valued-function B copy containing literally S.

This proves an implication on ONE Q', not two unrelated witnesses or unrelated
labelled maps. Its Lean statement explicitly retains all selection, external
coverage and class assumptions.

## Non-consequences / adversarial boundaries

* U-irreducibility alone does NOT imply ordinary irreducibility; the
  K-membership argument above is necessary and visible in the statement.
* A source-defined ordinary homomorphism is not automatically the native
  homomorphism-embedding on the same selected map.
* The result does not establish that Q' is the exact canonical encoding of
  some H-member, nor that an arbitrary decoded native Q' belongs to H.
* It proves internal native B-coverage, not the strict full-functional local
  B-tree completion at every small test. This latter obligation is separate.
* The independent 2019 closure-profile construction in
  AllThoseRamseyClasses/Published must still be identified with the relevant
  whole-mask/part-tag presentation before one can compose the two developments.
* No validation marker for the historical total-fibre functional theorem is
  promoted by this conditional theorem.
