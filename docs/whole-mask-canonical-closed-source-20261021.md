# Canonical whole-value tags are 2019 U-closed — 21 October 2026

Take an embedded full old input-root pattern corresponding to a fixed function input equality pattern and nonempty output-part mask. The embedded old root contains the persistent active mask-domain predicate. By its definition, the original partial function is defined on the corresponding input tuple with a set U whose image under the part map is exactly the mask. For each part in the mask choose one corresponding vertex of U. Transversality makes that chosen vertex unique within its part. Every element of U has a part in the mask and must equal that part's chosen vertex, so the resulting tuple enumerates the **entire** value U. It therefore satisfies the complete-value output relation and, by the original full-root embedding, the canonical fresh tag. The root prefix is unchanged.

The previous semi-closedness theorem already ensures that no invalid closure tuples occur and that two tuples over a fixed root are equal. Adding existence above every embedded root proves canonical 2019 U-closedness of the TAGGED SOURCE, for the positive-input/positive-output closure description. This is not an arbitrary tagged target decoding theorem, and does not construct compatible strict functional target trees. A defined-empty value is kept in the old mask-domain data and generates no closure vertex; nullary function inputs require a separate root-zero reduction.
