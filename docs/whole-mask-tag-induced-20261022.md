# Canonical complete-mask tags commute with exact vertex induction

The old relational input-root pattern for a fresh complete-value closure tag is an induced full structure on all distinct input vertices. Every one of these vertices occurs as a prefix coordinate of the closure tuple. If the tuple belongs to an exact induced carrier S, then every vertex of the ambient embedded root belongs to S. Restrict the ambient full root embedding to the induced structure E|S, preserving and reflecting all old relations. Conversely compose an embedded root in E|S with the full inclusion to obtain an ambient embedded root. The old complete-value relation itself is induced literally in either construction. Thus the tag expansion of E|S and the induced ambient tag expansion on S have exactly the same relations (indeed are definitionally related by an identity embedding in both directions).

The exact carrier never grows. This is a structural relation theorem, not an assertion that domain predicates recomputed from a partially forgotten function agree with persistent ambient domain masks. It supplies the needed step for keeping the source's semi-closed whole-fibre weak tests in the 2019 language.
