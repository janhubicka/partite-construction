# Two different missing-output mechanisms under an EHN control projection

**17 October 2026 — English proof and adversarial audit BEFORE Lean.**

The updated functional weak/U-closed crosswalk correctly keeps AMBIENT
per-output-part source masks and distinguishes ordinary weak restriction
from function closure. One additional distinction is indispensable:
the ambient ROOT profile on the **actual source** does not necessarily
agree with the output-root profile of the functional CONTROL under an
EHN projection. The projection is only source-defined original-partial.
It does NOT reflect function domains at undefined input tuples.

This note makes that semantic limitation explicit, checks the correct
positive replacement, and links it to the already formalized reducible
input-hull case. It changes neither the published manuscript nor the
verified recursive closed Ramsey construction.

## Definitions and exact dichotomy

Let B be a genuine transversal functional partite System with part
map p:V→P and with verified \`B.WeaklyPartiteOver D\` to a functional
control D on P. Let S⊆V be an EXACT weak vertex test and all inputs
of a symbol F lie in S. Fix one output part q∈P.

Call q a *CONTROL-MISSING slot* when

\[
q\in F_D(p\bar x)
 \quad\text{and}\quad
\neg\exists y\in F_B(\bar x)\cap S:\ p(y)=q.
\]

There are exactly two mutually exclusive causes.

**(1) Undefined-source/phantom slot:** the ambient full source
fibre \(F_B(\bar x)\) is EMPTY and the control fibre contains q.

**(2) Omitted-source-value slot:** the ambient source fibre has
the UNIQUE q-valued output y, but y lies OUTSIDE S.

Proof: If the source fibre is nonempty, the EHN fibre-exactness
theorem \`IsEHNHomomorphismEmbedding.map_func_of_nonempty\`
says

\[
p[F_B(\bar x)]=F_D(p\bar x).
\]

Thus the control output q is represented by a source output y of
part q. Since no such output remains inside S, q is exactly the
missing active root slot of the ambient source. By transversality
this outside source output is unique. Conversely, either the
source is undefined, or the source output exists but is omitted
by S; both cause a missing q in the exact weak restriction.
The two causes are disjoint by nonemptiness.

For an arbitrary weak set the source-root transport theorem handles
(2), but **cannot** replace (1): source-side ambient masks are
completely absent at undefined inputs, while the D-control still
has the slot.

## Closure eliminates (2), not (1)

If S is genuinely function-closed in B, every actual source output
of inputs in S lies inside S. Therefore a control-missing slot can
occur ONLY because the source fibre is entirely undefined:
the missing slot is equivalent to the undefined-source/phantom case.

The existing source/domain-failure lemma then proves that the
FUNCTION-CLOSED HULL generated by the input tuple is REDUCIBLE,
i.e. admits a proper full functional free decomposition. This
hull appears ONLY as a diagnostic of the existing source
structure, not as a replacement for the weak test S or its
cardinality in the induction.

This is a promising bridge to the corrected induction: source
lost-output defects have exact coherent root-preimage witnesses;
a phantom control output produces a reducible closure-separator
case. But constructing a SHARED strict target B-tree completed
root with all HJ projected histories is still a separate lemma.

## Adversarial audit

* **Projection fullness is false:** the existing two-disjoint-B-copy
  binary-function example has an undefined cross-copy source input
  whose projected D-input is defined. Such a phantom output cannot
  be detected by SOURCE missing-ambient masks. This distinguishes
  the new statement from earlier source-root coherence.
* **Nonclosed weak test:** unary F(a)={b} with a∈S and b∉S
  realizes (2). An assertion that ALL control-missing slots imply
  undefined source domain would therefore be false.
* **Genuinely multivalued outputs:** if F(a)={b,c} with
  p(b)≠p(c), and weak S retains b but omits c, only the c-part
  is missing. The nonempty-source fibre EHN equality correctly
  distinguishes it without singleton-valuedness.
* **Transversality:** used to identify the actual omitted source
  output uniquely, not to assert a global injective part map.
* **Root markers:** when S is function-closed in the source but
  the selected control alpha(A) has a defined value on a projected
  tuple with source domain undefined, the occupied A-subset may
  still be nonclosed. Closedness of source S does not repair it.
* **Defined-empty values:** \`Option (Set)\` has a separate
  defined-empty bit. This note uses the original-2019 convention
  with empty fibre meaning undefined and does not erase that
  independent requirement.
* **Nullaries:** EHN fibre exactness and the diagnostic input-hull
  reducibility statement do not need positive arity, but may rely
  on the canonical nullary closure root already represented in
  the Structure interface.
* **C5/parity:** the case split alone does NOT supply a common
  admissible strict tree completion for arbitrary stage roots.
  The rank-(n−1) predecessor and genuine HJ histories remain needed.
