# Unique complete output-mask domains under OLD free amalgamation — 22 October 2026

The complete-mask 2019 U-closure description treats each positive output-part mask as an independent closure symbol. U-closedness alone does **not** force masks of different symbols over a common primitive input to represent one set-valued function. The OLD domain mask relations must satisfy a separate necessary law: when two domain masks (q₁ and q₂) are active on the same distinct-input equality-pattern root, their unordered output-part label sets coincide. Different enumerations of that same set are permitted.

Canonical genuine partial functions satisfy this law, as previously verified in `WholeMaskActiveRootExtraction.lean`. It passes to exact induced OLD restrictions, whose ambient domain bits persist independently of whole-weak function deletion.

The new theorem says a genuine OLD *full relational free amalgam* of three coherent mask-domain structures is coherent. Same-side activations follow from side coherence. In the mixed case, the two domain tuples are supported by the exact same whole input root, so each root vertex belongs to the common intersection; full root embeddings pull both masks into the common base where they agree.

This is necessary target bookkeeping, but not sufficient to decode an arbitrary U-closed tagged graph into a coherent genuinely partial function structure. The target also needs existence/uniqueness for all coherent complete-value relations and part-transversal outputs. No strict functional B-tree target completion is claimed.
