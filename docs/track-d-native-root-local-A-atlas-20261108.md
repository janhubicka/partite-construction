# Track D: the canonical local A-atlas of a native Hales–Jewett separator

**8 November 2026. Scope:** adversarial research note for draft [PR #573](https://github.com/janhubicka/partite-construction/pull/573). The frozen Appendix A manuscript is not edited. New declarations are candidates until the **exact-head full Lean build and named axiom audit** pass.

## Source and actual root

Let `C` be a genuine function/relation structure with set-valued fibres and `p:C→A` an EHN homomorphism-embedding. In a genuine native EHN attachment, `C` may be the exact full-function-closed `closedTestPullback(...).common` separator and `p` is the *canonical*, possibly noninjective, selected-`A` projection `WR.part ∘ pb.commonMap` established by `closedTestPullback_common_EHN`.

For every **literal root vertex** `x∈C` define the full function-closed hull

\[
H_x = \langle\{x\}\rangle_{\mathrm{func}} \subseteq C.
\]

This closure need not have one vertex or any bounded cardinality, but it is **generated by at most one** vertex. The verified `irreducible_of_one_generated` therefore makes the FULL induced `C|H_x` irreducible. Applying the EHN irreducible-protection clause yields a FULL embedding `e_x:C|H_x↪A` satisfying the exact pointwise law

\[
e_x(z)=p(z)\qquad\text{for every }z\in H_x.
\]

In particular `p|H_x` is injective. The hull includes `x` and these hulls cover all root vertices. **On true source overlaps** `H_x∩H_y`, the two embeddings necessarily agree pointwise because both are literally the restriction of `p`.

## Precisely what is NOT established

1. **False extra hits:** even though `e_x` and `e_y` agree on `H_x∩H_y`, their images in `A` may intersect at points that are NOT the image of any common root vertex. Equivalently, `p(z)=p(w)` can occur for distinct `z,w` in different hulls. The local charts do not make the global projection injective.
2. **Cross-chart relation reflection:** the actual source may have no relation incidence on a tuple that mixes different charts, while the selected target `A` does have that relation on the projected tuple. Full embeddings would need reflection of every relation; EHN only supplies weak preservation globally.
3. **Source-undefined function domains:** EHN is source-defined original partial semantics. A tuple involving vertices from different charts may be source-undefined but have a defined target fibre. The verified `FibreExactness` theorem only guarantees equality of whole output fibres when the *source* fibre is nonempty. Full target-fibre embedding would need domain reflection as well. `Option (Set)` defined-empty values remain a distinct representation issue and are NOT modeled by identifying empty fibres with defined-empty values.

Thus the local atlas cannot be glued into a single FULL `Root↪A`, nor can one freely identify independently completed strict `B`-trees over it. The original 2019 partial projection of the entire root into one copy of `B` **does** exist (`native_closed_separator_originalPartial_oneCopy`), but the two side completions must extend this *same* root map while retaining the actual history and irreducible-copy constraints.

## Positive cases and remaining geometry

- If the **whole separator** is generated by the input tuple of one ACTUALLY NONEMPTY source function fibre, it is irreducible, so its EHN projection becomes one FULL `Root↪A`. Draft [PR #571](https://github.com/janhubicka/partite-construction/pull/571) then obtains compatible strict relative completions under explicit side generator-rank predecessor conditions. If `p` is noninjective, such an active tuple cannot generate the whole root (the complementary proposed Lean gate).
- If the root fits inside aligned irreducible collars on both full sides, [merged PR #570](https://github.com/janhubicka/partite-construction/pull/570) supplies two compatible strict relative completions. Such collars necessarily have globally **injective** root labels, so they do not cover the collision case.
- The maximal mixed-root case with **colliding labels or incompatible cross-chart traces** still requires a history-dependent strict target-tree completion. A useful next object is not another arbitrary global `A` mark, but a finite B-tree target carrying a **coherent family of local full A-charts** with an explicit rule excluding extra target-root identifications and handling cross-chart source-undefined function tuples.

No weak tested vertex set is enlarged to its function closure; each `H_x` is a separate full-root diagnostic object. No full `n`-pass functional sparsening theorem is implied.
