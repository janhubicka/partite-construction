## Claim that must NOT be made

It is false to drop the positive primitive-arity hypothesis from the final
whole-mask cross-pattern value-uniqueness or decoder theorem while retaining
only 2019 U-closedness, full-root tag normality, OLD domain/root validity,
and the protected closed U-irreducible canonical B-copy coverage.

The failure persists even if the target contains full embedded B-copies and
all OLD domain masks are coherent.

## Two-vertex counterexample

Take one primitive **nullary** genuinely partial function F, with its output
set regarded as `Option (Set V)`, and a one-element part carrier P={p}.
Let B have one vertex b in part p and let F_B()=some {b}. There are no
primitive relation symbols. Its OLD complete-mask language has a nullary
domain relation for F with the one-part mask q=(p), and a **unary** complete
output relation for the same pattern and mask. The canonical OLD graph of
B has both the nullary domain tuple and the unary output tuple (b).

Let C have two vertices c₀,c₁, the SAME active nullary domain relation,
and complete unary output relations on **both** (c₀) and (c₁). There are
no other OLD relations, and no fresh closure tuples.

Every input equality pattern for F has root size zero: a surjection
Fin(0)→Fin(m) forces m=0. Since the 2019 complete-mask closure rules
require a positive input root, this signature has **no fresh closure
rules at all**. Thus C is U-closed, fresh-tag normality holds vacuously,
every OLD output tuple has its valid empty root and active domain mask,
and its active output-part mask is unique.

Each singleton of C is fully isomorphic to the canonical tagged B, and
the size-two induced structure is U-reducible (indeed a free amalgam of
its two unary singleton structures over the empty structure). Hence
all closed U-irreducible embedded tests of C fully embed into canonical
tagged B. This is precisely the protected-copy coverage hypothesis.
C even contains two FULL B-copies.

Nevertheless the two complete OLD graph tuples give different full
values for the SAME literal nullary input:

    F() = some {c₀}      and      F() = some {c₁}.

No genuine partial function on C can realize both tuples. The generic
decoder must choose arbitrarily and cannot be faithful to the entire
OLD graph. This is not merely an empty-carrier or defined-empty defect.
