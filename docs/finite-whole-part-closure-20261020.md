# Exact closure and generator bounds from finite whole-value relations

The complete-output-part relation records **every** defined finite value, with all output vertices simultaneously, and each relation tuple is labelled by the output parts. A subset T is closed exactly when, for every such tuple, containment of its function input coordinates in T implies containment of all its output coordinates. The forward implication is the original definition of function closedness. The reverse uses the previously proved finite output enumeration to represent any defined value with such a relation tuple. Inputs may repeat and outputs may equal input vertices. The empty-defined case creates no closure vertices.

Intersecting these closed subsets gives the same vertex-closure hull as the original partial-function operations. Consequently a finite generating-set bound is identical on the original source and its finite relational complete-part presentation. No ambient closure hull is added to weak test vertex sets.

The representation is **not yet** the 2019 U-closed expansion: it still needs full induced equality-pattern roots, explicit active root/domain relations, and a closure description in which every active root has one complete value tuple. In particular the mixed target-tree completion step remains open.
