# Covered final targets cannot confuse undefined with defined-empty — 22 October 2026

The complete-mask OLD language has a domain predicate for each input equality pattern p and each output-part mask q. For a ZERO-length mask, the predicate means that the primitive partial application is defined with a value consisting of zero outputs. It is not equivalent to a missing domain predicate, which represents undefinedness.

In any final U-closed tagged target C whose closed U-irreducible tests embed fully into canonical B, an active zero-mask domain tuple on root r has ordinary irreducible support range(r), so that exact weak support embeds fully in canonical B. Reflect the domain tuple into B. Its active output mask is the empty set, forcing the true partial function value of B to be some empty set (no vertex can have a part belonging to an empty set). Consequently B has the corresponding complete OLD output graph tuple, with NO output positions. Full reflection along the exact support embedding gives the OLD complete graph tuple back in C.

Thus defined-empty domain records in C have a complete zero-output graph tuple on exactly the same input vertices, including for nullary primitive functions. No positive-output fresh closure rule, transversal target assumption, extra output vertex, or weak-test hull replacement is used.

This is one necessary final decoding law, not a proof of cross-pattern output compatibility or compatible maximal-mixed functional B-tree completions.
