# Complete output values are invariant under distinct-input equality patterns — 22 October 2026

**English proof, independent mathematical audit before Lean validation.**

Let C be a final U-closed complete-mask tagged structure whose closed U-irreducible tests fully embed in the canonical tagged representation of one genuine partial set-valued structure B. Assume tag normality, OLD complete-output root validity, and positive input arity. These local target laws have already been formally deduced from that same coverage assumption in merged #470–#471.

Fix a primitive function symbol F, its *literal* input tuple x, and TWO OLD complete output tuples with potentially different distinct-input sizes m1/m2, surjective argument maps r1/r2, and different full output-part masks q1/q2. Each root has exactly the same set of input vertices as x because r1 and r2 are surjective. The first active domain tuple makes this exact input set an ordinary irreducible seed. Therefore its U-closure H is U-closed and U-irreducible, so protected B-copy coverage gives **one full embedding** of H into canonical B.

By the previously merged normalized-target output-hull lemma #472, each output vertex from either OLD complete tuple belongs to H. Consequently BOTH complete output tuples are transported through this SAME embedding of H to canonical B. Their primitive argument tuples there equal g ∘ x_H, independent of the chosen equality pattern. Each canonical B graph relation says its complete image set equals the actual value of F_B(g ∘ x_H). Both values are therefore equal by functionality. Injectivity of g reflects equality of the **original full output VERTEX sets**, not just their output-part label sets.

This proof applies to non-singleton multivalued outputs and defined-empty masks (which have no output positions). It uses no transversal property for comparing the outputs; transversality is a separate permanent partite invariant. Positive primitive arity is essential for the closure-tag root argument; nullary functions require the zero-root case already separated from the 2019 closure rules. The U-hull appears only as a *target comparison witness* and must never be substituted for the exact weak source test S or its projection f[S] in the iterated induction.

The result is a normality component for the **final** covered target. It is not a proof that every intermediate picture admits compatible strict functional B-tree extensions across a nonclosed maximal-rank mixed root. That mixed-step geometric obligation remains OPEN.
