# Canonical source decoding and full OLD embedding inverse

26 October 2026.

The canonical OLD complete-mask relational representation of a finite genuinely partial Option(Set)-valued source A, with output-part-transversal fibres, decodes to literally the same source structure, not merely matching function values on selected input tuples. This follows by structure extensionality from the previously verified canonical source relation and function round-trip theorems.

Consequently a FULL OLD complete-mask relational embedding of canonical source A into canonical target B is a FULL genuinely partial function embedding A→B on exactly the same vertex map. Domain reflection is obtained from the source OLD domain relation (including defined-empty masks and all input equality patterns); entire value equality is obtained from the full output tuple relations. This is the inverse direction of the now-in-review forward full part-preserving embedding functor PR #501.

Caveat: an isolated vertex's external part assignment is not encoded by the OLD function graph; the inverse does not claim an arbitrary OLD embedding preserves all part labels. This has to be handled with an explicit part-preserving hypothesis or unary-part predicates when transferring general Ramsey arrows. No weak source subset is enlarged and no false maximal mixed strict functional B-tree completion is assumed.
