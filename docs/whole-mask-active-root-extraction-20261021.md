A full original old relational pattern on an active input root is obtained by pulling back **every** old relation along the injective enumeration of the distinct function arguments. The resulting root contains the active mask-domain relation by construction, and that enumeration is a full induced embedding of the root into the old ambient structure. Repeated primitive arguments have already been factored through the surjective equality pattern, so no vertices or closure hulls are added.

For a canonical genuine source, the active OUTPUT PART SET is uniquely determined by the original defined function value.
