# Final B-covered targets have valid distinct-input roots for EVERY active mask domain

22 October 2026.

Arbitrary relational targets can have OLD complete-mask domain relations over roots whose supposedly distinct coordinates are repeated. This is not excluded by 2019 U-closedness. To decode a faithful partial function, one must establish injectivity also for active domain tuples WITHOUT an accompanying complete output graph tuple. The previously merged covered-domain theorem #470 established graph tuple validity, but did not establish this converse.

Take the exact vertex support of an active OLD domain relation. It is ordinarily irreducible because the domain relation includes every listed root coordinate. The 2019 protected-final-copy invariant gives a FULL embedding of that exact weak induced support into the canonical OLD graph of B. The active domain tuple reflects to B, whose definition includes injectivity of the distinct input root. Since the embedding is injective, the root tuple in the final target was injective too.

This proof handles zero-length output masks and nullary roots (where injectivity is vacuous), requires no target transversality, and changes no weak test. Combining with the already proved positive-domain completeness and defined-empty witness lemmas is the next semantic step. The strict maximal-mixed functional B-tree target existence remains open.
