## The useful valid predecessor-boundary lemma

Fix the previous genuine functional control D and a full selected
placement alpha:A↪D. Assume the verified *ordinary* strict
functional weak-history invariant of rank m for D: for every exact
weak vertex set of cardinality ≤m and every finite projected history,
there is a genuine strict full-functional B-tree completion, an
ambient-relative weak HE, and protection of intersections with
every actual full ambient A-copy.

Given a finite projected side test I⊆D, form the **auxiliary finite
control test**

    J = I ∪ alpha[A].

**Extra hypothesis: |J|≤m.** This is a numerical assumption, not
an assertion of root-extension existence.

Request the predecessor witness on **J** and include all singleton
subsets of the finite control carrier in the history. The existing
ambient A-copy intersection certificate supplies a full marked
A-copy e:A↪T with

    f(alpha(a)) = e(a)   for every a∈A,

because all alpha(A) is now present in J. Singleton projected
histories force f to be injective on the exact test J. Consequently

    f(x)=e(a)  <=>  x=alpha(a)      (x∈J,a∈A).

Restrict this witness back to the ORIGINAL exact I. A restricted
ambient-relative weak HE still has full fibres on every source
defined input all of whose outputs survive in I; actual ambient
irreducibles and full A-copy histories remain protected. The
restriction neither creates missing operation values nor demands
reflection of undefined input domains. The same full target mark
is now safe on I. The target B-tree has NOT been enlarged or
re-glued.

This gives a sound full protected alpha-collar on I **whenever**
|I∪alpha[A]|≤m. Its source remains the exact weak D|I, not D
induced on a function closure. Only the auxiliary predecessor
request has extra explicitly counted vertices.

A still more general unconditional extraction works without the
budget condition: on occupied labels alpha(a)∈I the mark is already
exact by ambient-copy control and singleton history; only the
unoccupied alpha positions can carry false hits.

## Mixed binary functional attachment corollary

Let C = Left *_Root Right be a **FULL** functional free amalgam
with an EHN projection p:C→D and let the actual attaching root
project into alpha[A]. Let S⊆C be an exact finite **mixed** weak
test with |S|≤n, meeting each side's complement. Define exact
side projected images

    I_L = p[S∩Left],    I_R = p[S∩Right].

Because S is mixed and the side injections are full,
|I_L|,|I_R|≤n−1. The *stronger* budget hypothesis is

    |I_L∪alpha[A]|≤n−1
    and
    |I_R∪alpha[A]|≤n−1.               (★)

The rank-(n−1) predecessor invariant on D now provides two
full protected alpha-collar witnesses by the preceding lemma,
one on each auxiliary J_L,J_R. Restrict them back to I_L,I_R,
and EHN-pull them back to the two exact weak source sides. Their
full alpha marks agree at all source root vertices since those
project to alpha[A]. The verified
`IsFreeAmalgam.protectedAMarkWeakTree_glue` therefore merges the
two target strict B-trees over complete full marked alpha copies,
preserving ambient full-A histories and arbitrary projected
histories. The conclusion is a STRICT genuine full-functional
weak B-tree witness for the ORIGINAL exact S.

This statement does NOT assume the false global
`AtMostProtectedWeakTreeWitness` predecessor property. It uses
only the actual **ordinary** rank-(n−1) invariant plus (★).
It is a legitimate special-case rank increment rather than a
conditional tautology about arbitrary relative completions.

* **Closure:** Even if alpha[A] is not function-closed relative to

  since the predecessor invariant is on **weak** exact vertex

  disappear in I imposes no spurious target fibre-equality

  the restricted witness remains fibre-surjective. Distinguish
  that from the false global total-fibre map.
* **Transversality:** All actual functional partite stages retain

* **Several HJ lines:** The corollary treats ONE free attachment

  Existing common-coordinate retraction results are separate.

## Quantitative remaining gap

The only rank-increment cases not covered by (★) have some side
with an *unaffordable missing boundary*:

    |alpha[A] \ I_side| > (n−1) − |I_side|.

In particular a side using all n−1 available projected parts
cannot afford even one additional alpha part. These are precisely
where a **test-dependent completed weak-root profile** is needed
instead of a fixed alpha mark. Its map may identify reducible
boundary vertices, and its relative extensions must be synchronized
across successive genuine HJ line attachments.

The validated relational Appendix A proof glues over partial
induced A-substructures, which are automatically legitimate
relational roots; the functional translation cannot do so when a
partial A-root is not function-closed. The budgeted lemma avoids this
problem by using the full alpha-mark *only when the predecessor
has enough vertex budget to see it*.
