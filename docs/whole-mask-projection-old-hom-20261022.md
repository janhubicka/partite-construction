# Partial projections and complete OLD graph homomorphisms

An original-2019 partial map preserves every *defined* source whole-value fibre exactly, without demanding reflection of undefined source inputs. If it also preserves part labels and remains injective on each active old distinct-input root, its canonical complete-mask relational graph mapping is a homomorphism.

The root-injectivity hypothesis is essential. The domain relation lists every distinct input vertex; its target image must remain injective. For each source value U the projection sends the entire set to its image, while part-map preservation keeps the ordered output-part mask unchanged. A complete output relation induces its active domain relation, so the same hypothesis protects both kinds of tuples.

The converse direction, interpreting positive OLD graph homomorphisms as original-partial projections, is investigated independently in PR #487. Neither direction claims domain reflection, strict functional tree completions, or any enlargement of weak tests.
