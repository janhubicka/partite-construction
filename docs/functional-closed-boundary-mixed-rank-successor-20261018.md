   closed. We use only their vertex injectivity to derive strict

3. **Exact weak test.** S is neither enlarged by function closure
   nor replaced by a graph encoding. Missing source values remain

   part transversality invariants are retained.
4. **Function-closed H is ESSENTIAL for the current gluing lemma.**
   If F(a)=b with a∈H and b∉H, freely attaching another B-copy

   diagnose this case but do not yet produce compatible strict

   one source side does not force a predecessor cardinal drop;
   it uses the already checked pure-core or pure-copy invariant
   from the actual Hales–Jewett Picture. Therefore this lemma
   is deliberately scoped to genuinely MIXED tests.
6. **Parity and C5 remain.** This theorem does NOT assert
   protected fixed-α marks for arbitrary rank-m histories:
   it extracts marks only for the particular closed occupied
   H's. The odd-path parity audit forbids the unrestricted
   mark statement, and the arbitrary-stage C5 audit forbids
   a universal nonclosed-root completion theorem.
7. **Irreducibility.** B is irreducible as required; A irreducible
   is still a technical hypothesis in the current EHN ambient

8. **Nullaries:** the lemma is conditional on the actual full
   free attachment, its genuine closure predicates, and the
   full EHN invariant; it does not infer an empty root merely
   because the tested S happens to be empty.
9. **Remaining gap.** This proves one substantial branch of the
