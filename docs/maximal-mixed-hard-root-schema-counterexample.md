## Counterexample: two forest stages and a five-cycle

Use the function-free relational language of simple undirected
graphs. Set `A=Base=B=K₂`, `Control=D=K₅`, and `n=5`.
Take `K` to be all finite structures of the language, a free
amalgamation class. The finite control labels are `0,1,2,3,4`;
let `alpha:A→D` select the edge on `0,3`.

The **old** `D`-partite stage is the disjoint union of:

```text
    a0 ----- b4 ----- b2 ----- a3       u0 ----- u3
    0         4        2         3      0        3
```

The **core** `D`-partite stage is the disjoint union of:

```text
    c0 ----- d1 ----- c3                w0 ----- w3
    0         1        3                 0        3
```

Subscripts give part labels. Every listed edge has distinct parts,
so the part projections are EHN homomorphism-embeddings into the
complete control `K₅`: any irreducible source is contained in
a singleton or an edge and is projected as a full embedding.

Both stages are **forests**, hence strict trees of copies of the
irreducible base edge `B=K₂`. Consequently they satisfy
`LocallyGeneratedOriginalPartialTreeCompletable B _ 5`;
indeed they satisfy it at **all** generator ranks.

The old selected A-support on parts `0,3` is the full induced
substructure on `S={a0,a3,u0,u3}`: the independent pair
`a0,a3` and the separate edge `u0--u3`. Embed it FULLY into
the core via

```text
     a0 ↦ c0,   a3 ↦ c3,   u0 ↦ w0,   u3 ↦ w3.
```

The source support and its image have exactly the same relations.
The extra support edge makes the selected alpha placement
**genuinely active** (it is not an irrelevant/empty A-copy case).

Form one actual native binary full free attachment
`UnitAttachD Old S Core f`. It contains the **closed** five-vertex
test

```text
    c0 ----- d1 ----- c3
     |                |
     b4 ------------ b2

    edge list: c0--d1, d1--c3, c3--b2,
               b2--b4, b4--c0
```

All five vertices project to **different** control parts:
`{0,1,3,2,4}`. Thus `G=Test` has exactly five elements,
generates the whole test (no function symbols), and
`|(G.image part)|=5=n`. This is the **maximal** projected-rank
case, with NO collision to invoke the predecessor induction.

The test meets both sides beyond their common separator:
`d1` belongs exclusively to the core and `b4,b2` exclusively
to the copied old stage. The actual common full-functional
separator is `{c0,c3}`, an **independent** two-point graph.
In a function-free language it is *not* generated by at most
one element.

Suppose the hard-root schema supplied some strict common B-tree
`Start`, a map `q` from this separator, and two compatible
original-2019 partial-function strict relative extensions of the
tested sides. The already verified theorem
`IsFreeAmalgam.originalPartialTreeCompletion_glue_relative`
would give a homomorphism-embedding of the five-cycle into a
strict tree of copies of `K₂`. Every strict `K₂)-tree is
bipartite, and an odd five-cycle admits no graph homomorphism
to a bipartite target. Contradiction.

**The freedom to choose `Start,q` does NOT help.** Unlike the
previous fixed-A-label counterexample, this full source cannot
be completed by any root map whatsoever.
