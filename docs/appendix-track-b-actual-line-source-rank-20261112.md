## Finite rank-separation regression (mathematical audit; not a new Lean theorem)

The need to distinguish the two tagged encodings is not cosmetic: their minimum-generator ranks may be different even for an output-transversal native system. Take one unary function on vertices `a,b,c`, with `F(a)={b,c}` and all other fibres empty. Give `a,b,c` three distinct part labels, so every output fibre is transversal. On the **same exact weak carrier** `S={a,b}`:

- Native clipped weak restriction keeps `F(a)={b}`, hence `S` is generated by `{a}` and has generator rank **1**.
- Genuine `Option(Set)` whole-fibre weak restriction deletes the entire value `F(a)` because `c∉S`; no operation generates another vertex, hence the minimum generator rank is **2**.

By the already verified separate dictionary theorems, the corresponding ambient split-output and whole-mask USize predicates inherit precisely these different bounds. Thus replacing one USize by the other in an n-generator induction is invalid without an explicit no-partially-retained-fibre/closed-test hypothesis. This elementary example is provided for adversarial inspection only; it is **not claimed as a newly compiled Lean regression** in this PR.
