# A native strict functional mixed-step theorem when the occupied A-boundaries are closed

**17 October 2026 — English proof, checked against the 2019 relational argument.**

Fix a true FULL functional free attachment \(C=L*_{R}M\), its
original-partial/EHN part projection \(p:C\to D\), and a selected
FULL copy \(\alpha:A\hookrightarrow D\) containing the projection
of the actual attaching root. Assume \(A\hookrightarrow B\) is
a FULL embedding, and \(B\) irreducible.

Let \(S\subseteq C\) be an EXACT finite weak test with at most
\(n\) vertices, genuinely mixed between both source sides.
Set
\[
 I_L=p[S\cap L],\qquad I_M=p[S\cap M],\qquad
 H_L=\alpha^{-1}[I_L],\quad H_M=\alpha^{-1}[I_M].
\]
Since \(S\) meets both side complements, both exact projected
side images have at most \(n-1\) vertices.

**New relative hypothesis:** \(H_L,H_M\) are FUNCTION-CLOSED
in the selected control \(A\). This is the faithful native
analogue of having legitimate \(U\)-closed partial \(A\)-roots
on both sides.

Suppose the preceding control \(D\) has the ORDINARY strict
full-functional weak-history local \(B\)-tree property at cutoff
\(n-1\), with actual ambient \(A\)-copy intersection certificates.

For each side image \(I_i\), request its predecessor witness
using the caller's finite projected-history list PLUS every
singleton control part. By the relative fresh-\(B\)-copy lemma
\`protected_of_closedOccupiedA\`, valid because \(H_i\)
is FULL/FUNCTION-CLOSED, the witness can be extended (on its
TARGET side only) to have a genuine full \(\alpha\)-marked
\(A\)-copy whose exact trace is the input weak test \(I_i\).
The extension adds **no tested source vertices**, and does not
take a function closure of \(I_i\).

Pull the two protected witnesses back along their actual EHN
side-to-\(D\) projections. The selected full source attaching
root projects into \(\alpha(A)\), so these marks agree on
the exact weak common source root. The verified
\`protectedAMarkWeakTree_glue\` freely glues the two
strict FULL-functional target \(B\)-trees over the WHOLE
marked \(A\)-copy. It supplies an ambient-relative weak map
on the ORIGINAL \(S\), preserving every surviving set-valued
function fibre, every actual full ambient \(A\)-copy
intersection, and all caller projected histories.

This is a **non-tautological special case of the true rank
increment**: it uses the ORDINARY predecessor at \(n-1\),
and only a structural CLOSEDNESS condition on the actual
occupied \(A\)-boundaries. It does not assume the false
uniform protected-mark predecessor.

## Adversarial audit

* **Relational languages:** All vertex subsets of \(A\) are
  function-closed. Thus the hypothesis on \(H_L,H_M\) is
  AUTOMATIC. The mixed-step proof reduces to the verified
  relational relative-labelled attachment mechanism, exactly
  as expected.
* **Unary missing output:** With \(F(a)=b\), \(a\in H\),
  \(b\notin H\), the occupied boundary is NOT closed. The
  fresh-copy free amalgam over \(A|_H\) is unavailable:
  the weak root may already have an output outside \(H\),
  and identifying only inputs could duplicate its value.
  This is excluded, not hidden in target-gluing axioms.
* **Parity example:** The false globally fixed \(\alpha\)
  root on a two-edge path is NOT inferred from tree
  completability alone. The predecessor rank-\((n-1)\)
  hypothesis and all actual ambient \(A\)-copy histories
  are retained. The obstruction's dense \(D\) lacks this
  predecessor property at the relevant rank.
* **Multiple HJ lines:** This is one binary attachment
  step, under a structural boundary condition. It does
  not imply the closedness condition for every mixed test
  in a general line family. The C7 test with small
  projected image still uses the previous-rank branch.
* **Function transversality:** All *source partite stages*
  keep per-fibre output transversality. The additional
  TARGET amalgam uses only genuine FULL function-closed
  embeddings, so it creates no conflicting output fibres
  even with set-valued functions.
* **Nullaries:** A=∅ only gives an empty legitimate root
  when the empty carrier is function-closed. The Lean
  theorem assumes the exact closure predicate; it does
  not invent an empty-root exception for nullary symbols.

**Remaining open:** Mixed tests where either \(H_i\) is
NOT function-closed, i.e., an ambient active output-part
mask does not survive in the occupied weak A-boundary.
The corresponding output needs a coherent completion
profile across both side targets. This is the precise
functional weak/U-closed difference; the source-root
mask transport theorem and full embedding criterion are
already separately validated.

**Formalization:** First extract the relative protected
